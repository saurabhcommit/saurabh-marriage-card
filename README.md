# Preeti & Saurabh — Divine Sangam (Vrindavan)

Static wedding invitation with a Radha–Krishna theme (25 Nov) and a Krishna–Rukmini theme (26 Nov). No build step.

Run: `python -m http.server 3000` → http://localhost:3000

Edit event text in `index.html`; calendar data is the `prog` array in `app.js` (times in UTC; IST = UTC+5:30). Confirm rights to `music/din-shagna-da.mp3` before public hosting, or swap in a flute/bhajan track.
